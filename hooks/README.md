# hooks/

`winners.md` (not created yet) will hold top-performing on-screen title texts and power phrases mined from Sandcastles exports, sorted by views. `editing/TEXT_HOOK_ENGINE.md` (sections 1 and 5) reads it on every edit.

Suggested format for each row: views · title text (line 1 / line 2) · formula (pain, outcome or state change) · power phrase · niche or source account.

Until it exists, every text-hook run flags `winners.md missing` and uses the starter power-phrase bank.
