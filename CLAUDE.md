# Project instructions

For any video / Reel editing work (captions, graphics, footage, cutaways, sound):
1. Follow `editing/QUALITY_STANDARD.md`. Read it before starting an edit and use its review checklist before presenting any version.
2. Use the @coach.agz brand in `editing/brand/BRAND.md` (colours, type, layouts, motion translations). Reference images are in `editing/brand/reference/`.
3. Run `editing/TEXT_HOOK_ENGINE.md` on every video edit before rendering anything else:
   - Build the frame-0 text hook from the edited cut's transcript.
   - Write the JSON block to that video's `edit_log.json`.
   - In chat, report only the winning lines, two runners-up and any flags.
